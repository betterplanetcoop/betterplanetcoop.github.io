# BetterPlanet Co-op Website

A warm, hopeful multi-page website for BetterPlanet Inc., a registered 501(c)(3) nonprofit dedicated to mission-driven entertainment, wellbeing tools, and free education.

## 🌍 Mission

BetterPlanet Co-op gives 100% of profits to charity while delivering:
- Mission-driven entertainment (instead of doomscrolling)
- Free wellbeing tools (gratitude journal, thank you notes, metime scheduler)
- Free educational content across 11 core pillars

## 📄 Pages

### 1. **index.html** - Home (Landing Page)
- Animated hero with warm gradient background
- Typewriter effect: "One video at a time" / "One purchase at a time" / "One act of kindness at a time"
- How It Works section
- Featured tools preview
- 11 Pillars icon grid
- Call-to-action buttons

### 2. **tv.html** - BetterPlanet TV
- Featured partners: Gaia, Sol AI, 30 Days for the Planet
- Filterable video gallery (11 categories matching our pillars)
- 37 YouTube videos embedded with real IDs
- Responsive grid layout

### 3. **about.html** - About Us
- Organization founding story (2000-2023)
- Core values & milestones
- Founder bio: Nicole Chernow-Martinez
- Link to founder's portfolio

### 4. **get-involved.html** - Get Involved
- 4 partnership tiers: Green / Community / Impact / Global Mission
- Other ways to get involved: Volunteer, Contractor, Board, Introduce Yourself
- Contact form with mailto integration
- 501(c)(3) nonprofit information

### 5. **tools.html** - Wellbeing Tools
- **Digital Gratitude Journal**: Write and save daily gratitude entries
- **Thank You Notes**: 5 warm templates + copy/download/email functionality
- **MeTime Scheduler**: 7-day weekly scheduler with drag-to-schedule blocks
- All tools 100% browser-based with localStorage persistence

## 🚀 Deployment

### To push to GitHub:

```bash
# Add remote repository
git remote add origin https://github.com/betterplanetcoop/betterplanetcoop.github.io.git

# Push to main branch
git push -u origin main
```

### To enable GitHub Pages:

1. Go to https://github.com/betterplanetcoop/betterplanetcoop.github.io
2. Click **Settings** → **Pages**
3. Select **Main** as the source branch
4. Save
5. Site will be live at: https://betterplanetcoop.github.io

## 🔒 Data Privacy

All tools save data **locally to your device** using browser localStorage. We do not collect, store, or sell any personal data. Your entries are completely private.
